# IA pour la maintenance des réseaux 5G
## Présentation

Ce projet utilise le Machine Learning pour optimiser et surveiller les réseaux mobiles 5G à partir du dataset Eurecom ElasticMon 5G (Kaggle).
Il vise à améliorer les performances réseau, réduire la consommation énergétique et faciliter la maintenance.

## Dataset
Eurecom ElasticMon 5G (Kaggle)
Contient des métriques 5G : RSRP, RSRQ, CQI, PRB, PDCP, etc.

Source: https://www.kaggle.com/datasets/abdopros/eurcom-network
## Modèles
### Modèle 1 :
Optimisation du temps de réponse
Prédit et aide à réduire la latence réseau.

### Modèle 2 : 
Optimisation énergétique
Estime et réduit la consommation d’énergie du réseau.

### Modèle 3 : 
Maintenance et détection d’anomalies
Identifie les anomalies pour anticiper les pannes.

# Outils utilisés

Python, Pandas, Scikit-learn, XGBoost, LightGBM

# Objectif

Améliorer la QoS, réduire la consommation énergétique et optimiser la maintenance des réseaux 5G.
